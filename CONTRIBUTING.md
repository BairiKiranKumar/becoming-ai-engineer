# Contributing

Thanks for helping make the course more accurate and useful.

We welcome **corrections, clarifying diagrams, accessibility improvements, reproducible fixes, and source updates** to lessons that have already been published.

## Before opening an issue or pull request

1. Check whether the guide is actually published in [ROADMAP.md](ROADMAP.md).
2. Describe the exact lesson ID (for example, `D13L02`) and relevant section.
3. For a technical correction, include an official source, minimal counterexample, or reproducible test.
4. Keep edits focused. Major curriculum changes need maintainer discussion because all 90 episodes have ordered dependencies.
5. Do not include unpublished production assets, private scripts, API keys, copyrighted third-party media, or personal information.

## Pull request checklist

- [ ] The change improves an existing, published lesson or was explicitly approved by a maintainer.
- [ ] Concepts, examples, and terminology are accurate and cited.
- [ ] Code was run or clearly identified as untested (do not fabricate verification).
- [ ] Images have useful alternative text; motion is not the only explanation.
- [ ] Previous/next navigation and relative paths still work.
- [ ] No credentials, personal data, or proprietary material were added.

For security-sensitive issues, read [SECURITY.md](SECURITY.md) instead of sharing exploit details publicly.

**Important:** Drafts for unreleased lessons are created in a private production workspace. Please do not open public PRs containing leaked or unapproved course material.
