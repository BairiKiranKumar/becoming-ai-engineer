# Security

This repository is educational. Any example that handles external models, private data, API keys or tool execution must explain applicable security constraints. Never use real customer information or production credentials in demonstrations.

- **Found an exposed credential or a sensitive vulnerability?** Do **not** open a public issue containing secrets or exploit instructions. Use GitHub's **Report a vulnerability** private reporting option if it is enabled for this repository; otherwise contact the repository maintainer privately through an established channel.
- **Found a broken example or non-sensitive security teaching error?** Open a correction issue with a reproducible, sanitized example.
- **Running code:** Review scripts before execution. Use test accounts and least-privilege permissions. Examples are educational, not production-ready by default.

The maintainer will confirm a disclosure channel before making this repository public.
