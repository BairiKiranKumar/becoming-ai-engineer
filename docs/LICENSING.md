# Licensing decision (required before launch)

This starter deliberately **does not assign legal reuse rights** to the author's lessons, diagrams, or example code without the owner's approval. Making a repository public does not automatically grant permission to reuse its content.

Recommended approach for a free educational project:

- **Written learning guides and original diagrams:** Creative Commons Attribution 4.0 International (**CC BY 4.0**) if you want others to reuse and adapt with attribution. If commercial reuse or derivatives should be restricted, choose a different license after considering the consequences.
- **Original example code:** MIT License if you want broad reuse in personal and commercial projects with attribution and warranty disclaimer.
- **Third-party assets:** follow their actual license; they are not relicensed merely by appearing here. Avoid redistributing proprietary model weights, images or datasets without explicit rights.

**Before the first public lesson:** obtain the owner's approval, add actual complete license texts, define which paths each applies to (for example `course/**` vs `examples/**`), and update the public README and contribution terms. Do not claim this repository is "MIT-licensed" or "CC BY-licensed" until those files exist.
