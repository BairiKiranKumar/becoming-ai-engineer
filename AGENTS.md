# Public Course Repository: Agent Instructions

This repository contains **approved public learning material**. The private video production tracker, raw footage, narration, drafts, storyboards, PR staging, and release approvals live in a separate workspace. Never import or publish private production data here.

- The immutable lesson IDs are `D01L01` through `D30L03`.
- The public catalog is `data/course_manifest.json`. `ROADMAP.md` is generated by `python tools/course.py roadmap`.
- Only publish a lesson when its complete and approved `course/.../README.md` and associated assets are ready. Then set its catalog status to `published` and `guide_path` to its approved `expected_path` in the same reviewed PR.
- Never mark a lesson published merely because a title exists in the plan.
- Explicitly requested local guide preparation may use catalog status `prepared` with `guide_path: null`; files must exist at `expected_path`. This is not approval to push, open a public PR, or publish. The roadmap shows no live guide link for this state.
- Prioritize detailed, accurate teaching and accessible diagrams; follow `docs/GUIDE_STANDARD.md`.
- The previous lesson must be precisely named in content; links to unpublished future lessons should point to the roadmap rather than to nonexistent files.
- Do not fabricate technical tests, citations, model results, or approvals.
- Run `python tools/course.py check`, then `python tools/course.py roadmap`, and verify generated files before submitting changes.
- Publishing and licensing decisions require human approval. Do not spend money, create public release PRs prematurely, or claim automated comment DMs work.
