# Getting Started

You do **not** need prior AI experience to begin. The course starts with basic concepts and progressively introduces mathematics, programming, model behavior, retrieval, agents, and production design.

## Recommended learning routine

1. Find the current topic in [ROADMAP.md](ROADMAP.md). If it's still marked **Planned**, the guide is not published yet.
2. Read its guide from the beginning. Review any listed prerequisites rather than skipping unfamiliar terms.
3. Draw or explain the diagram in your own words, then work through the example.
4. Try the exercise *before* opening the solution. Record any surprising outcomes.
5. Continue to the next lesson when you can explain the main idea and its limitations, not simply when the video ends.

## What you may need

- **Days 01–02:** a browser and willingness to learn. No paid AI product is required for reading the guides.
- **Later coding lessons:** Python and an editor. Each guide specifies the version, dependencies, and exact commands needed for its example; do not blindly install a global dependency list.
- **API-based examples:** keys may be optional or require paid access. Any such guide must label costs, provide safe key-handling instructions, and give a no-cost conceptual alternative where practical.
- **Math topics:** step-by-step worked examples and supporting explanations; take additional practice time if needed.

Do **not** commit API keys, private data, tokens, or credentials to GitHub. Do not execute code from an unreviewed pull request with elevated permissions.

## How to use this course as a beginner

The three lessons released each day form a sequence, but *you do not need to study three a day*. The schedule is for publishing, not your learning speed. Revisit the examples and earlier concepts as needed.

If you land on Lesson 37 directly, use the guide's **Prerequisites** and **Previously learned** sections to regain context.
