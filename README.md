## What will you learn?

Go from first principles to designing, evaluating, securing, and deploying real AI applications. We explain unfamiliar terms before using them, show concepts visually, and verify runnable examples rather than relying on AI-generated claims.

## How each lesson works

Every day contains **three real learning lessons**, not filler or promotional videos. Each Reel briefly connects to the previous lesson, teaches a **new** concept, and offers its own corresponding GitHub guide. You can join on any lesson: the guide provides the prerequisites and links back to earlier concepts.

1. **Watch** the educational Reel from the series on Instagram.
2. **Read** its individual GitHub guide, with diagrams, clear explanations, and deeper technical detail.
3. **Try** the exercise, runnable sample, or worked example and compare the verified expected outcome.
4. **Continue** to the next lesson through the [roadmap](ROADMAP.md).

Every released guide aims to cover the full *scoped lesson topic*: intuition, mechanics, visual explanation, examples, limitations, practice/solutions, and references. Larger disciplines cannot honestly be mastered in a single short video; the guide and linked further reading provide the necessary depth.

## Learning and accuracy commitments

- **Accessible first, technically accurate throughout.** We define terminology, show diagrams with accessible descriptions, and include equations when they matter.
- **Practice over hype.** Code results, examples, model behaviors, and performance claims are checked before publication. Tool versions and meaningful limitations are documented.
- **Connected but independently understandable.** Each lesson links to its predecessor and only links forward to lessons already published.
- **Free to read.** No paywall or compulsory sign-up for the learning guides.
- **Not a job guarantee.** Thirty release days are a compressed publishing format; proficiency comes from experiments, projects, feedback, and further study.
